Where to stream

Go live on Twitch straight from this page, no other app needed. This uses Twitch's WebRTC (WHIP) ingest, which is still in beta — if it won't connect, use the OBS tab.

YouTube doesn't accept a stream sent from a web page, so send it through OBS Studio (free):

  1. Click Open clean output window above.
  2. In OBS: Sources → + → Window Capture → pick “Stand-In Output”. On Windows use capture method Windows 10 (1903 and up).
  3. Right-click the source → Transform → Fit to screen.
  4. OBS Settings → Stream → Service YouTube → paste the stream key from YouTube Studio → Start streaming.

Streaming with a relay service that takes WHIP (it forwards to YouTube)? Use the Custom tab.

Share it in a call:

  1. Click Open clean output window.
  2. In Discord: Share your screen (or Go Live in a server) → pick “Stand-In Output”.
  3. For game streams, choose the Game + character scene first so friends see both.

Use it as your webcam:

  1. In OBS add the “Stand-In Output” window (see YouTube tab), then click Start Virtual Camera.
  2. Discord Settings → Voice & Video → Camera → OBS Virtual Camera.
  1. Click Open clean output window, then add it in OBS with Window Capture.
  2. Works for Twitch, YouTube, Kick, TikTok — anything OBS streams to.
  3. Want only the character, on top of other OBS scenes? Set Capture → Look → Green screen and the Character full screen scene, then add a Chroma Key filter (green) to the window source.
  4. Start Virtual Camera in OBS to use your character as a webcam in Zoom, Discord, Google Meet.

Any service that gives you a WHIP URL (for example a restream relay or a media server).
